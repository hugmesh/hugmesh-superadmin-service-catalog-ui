Optional services

Turn optional cluster services on or off after the image has shipped. An image boots with only the services it was built with; this is where a superadmin enables the rest.

Each row shows two different things. Requested is what the desired-state record says. Confirmed is what the controller reports it actually wrote. A request that is accepted but never acted on shows here as Not confirmed — this console never reads an accepted request as a running service.

Recorded on the service record as an audit note alongside your identity.
